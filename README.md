📖 Описание проекта

Vintage Threads — многостраничный сайт, посвящённый винтажной одежде. Он знакомит пользователей с концепцией бренда, представляет каталог вещей, галерею изображений и форму обратной связи.

Проект создан в рамках самостоятельной работы по веб-разработке с использованием ИИ. При создании сайта применялись HTML, CSS и JavaScript, а для хранения исходного кода и публикации проекта использовались Git, GitHub и GitHub Pages.

Главная идея проекта — показать, что винтажная одежда позволяет выразить индивидуальность, найти уникальные вещи и поддерживать более осознанное отношение к потреблению.

🎯 Цель проекта

Разработать современный многостраничный сайт с использованием нейросети в качестве помощника при создании кода, освоить основы веб-разработки, научиться работать с Git и GitHub и опубликовать готовый сайт в интернете.

🚀 Запуск проекта локально

Для работы с проектом понадобятся Git и Visual Studio Code.

1. Клонирование репозитория

Открой терминал и выполни команды:

bash
git clone https://github.com/souleater111/AI_vintage-threads.git
cd AI_vintage-threads

2. Открытие проекта

Открой папку проекта в Visual Studio Code:

bash
code .

3. Запуск сайта

Открой файл index.html в браузере. Также можно использовать расширение Live Server в Visual Studio Code для локального просмотра сайта.

🌐 Публикация на GitHub Pages

Сайт размещён с помощью GitHub Pages.

Чтобы опубликовать обновления:

Внеси изменения в файлы проекта.
Добавь изменения в Git.
Создай коммит.
Отправь изменения в репозиторий GitHub.
Дождись обновления опубликованного сайта.

Команды для отправки изменений:

bash
git add .
git commit -m "docs: update project"
git push origin main


Настройки публикации доступны в репозитории: Settings → Pages. Для публикации из корня репозитория выбери ветку main и папку / (root), если этот источник используется в настройках проекта.

🌿 Работа с Git

Git позволяет отслеживать изменения, сохранять историю разработки и при необходимости возвращаться к предыдущим версиям кода.

Пример рабочего процесса:

bash
git checkout -b test


После внесения изменений:

bash
git add .
git commit -m "feat: improve website functionality"
git push -u origin test


После проверки изменений их можно объединить с веткой main через Pull Request или командой слияния.

bash
git checkout main
git merge test
git push origin main


Ветка main используется для стабильной версии проекта, а test — для экспериментов и новых функций.
